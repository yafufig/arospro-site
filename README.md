# АросПро
Публичный сайт проекта «АросПро»: умные AR-очки для складов.

Статический HTML/CSS. Локальный запуск: `python3 -m http.server 8765`.
GitHub Pages: публикация из корня ветки main.
Домен: арос.tech (`xn--80a2aff.tech`).

Все сведения о стадии проекта основаны на презентации и уточнениях основателя. Изображение склада — оригинальная иллюстрация концепции, не фотография готового устройства или работающего интерфейса.

Шрифт Manrope: Google Fonts, SIL Open Font License 1.1. Текст лицензии в assets/OFL.txt.
