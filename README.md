# АросПро
Публичный сайт проекта «АросПро»: умные AR-очки для складов.

Статический HTML/CSS/JavaScript. Локальный запуск: `python3 -m http.server 8765`.
GitHub Pages: публикация из корня ветки main.
Домен: арос.tech (`xn--80a2aff.tech`).

Клиентская презентация: pitch.арос.tech, репозиторий `yafufig/arospro-clients`.
Vision Lab: lab.арос.tech, репозиторий `yafufig/arospro-vision-lab`.

Первый экран содержит студийный рендер дизайн-концепции очков. Изображение сгенерировано и не является фотографией готового устройства. Сценарий считывания показан интерактивной схемой в разделе о продукте. При уменьшении движения в настройках устройства анимация отключена. Калькулятор визуализирует условный сценарий сокращения времени на операцию.

Все сведения о стадии проекта основаны на презентации и уточнениях основателя. Изображение очков — дизайн-концепция, не фотография готового устройства.

Шрифт Manrope: Google Fonts, SIL Open Font License 1.1. Текст лицензии в assets/OFL.txt.
Прежний процедурный 3D-просмотрщик больше не подключается к странице; исходники и его библиотека сохранены для совместимости с ранее закэшированной версией. Внешних CDN и трекеров нет.
