# АросПро
Публичный сайт проекта «АросПро»: умные AR-очки для складов.

Статический HTML/CSS/JavaScript. Локальный запуск: `python3 -m http.server 8765`.
GitHub Pages: публикация из корня ветки main.
Домен: арос.tech (`xn--80a2aff.tech`).

Клиентская презентация: pitch.арос.tech, репозиторий `yafufig/arospro-clients`.
Vision Lab: lab.арос.tech, репозиторий `yafufig/arospro-vision-lab`.

Первый экран содержит оригинальную процедурную 3D-модель очков и коробки, сценарий считывания, управление поворотом мышью и клавиатурой. После одного показа анимация останавливается. При уменьшении движения в настройках устройства автоматическая анимация отключена. Для устройств без WebGL предусмотрена SVG-иллюстрация. Калькулятор визуализирует условный сценарий сокращения времени на операцию.

Все сведения о стадии проекта основаны на презентации и уточнениях основателя. Изображение склада — оригинальная иллюстрация концепции, не фотография готового устройства или работающего интерфейса.

Шрифт Manrope: Google Fonts, SIL Open Font License 1.1. Текст лицензии в assets/OFL.txt.
3D: Three.js 0.186.1, MIT; библиотека размещена локально, лицензия в assets/vendor/THREE-LICENSE.txt. Внешних CDN и трекеров нет.
